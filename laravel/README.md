# Базовая API для тестирования

### Стэк:

- Laravel 13 (PHP)

## При запуске:

Скопируйте `.env.example` в `.env`. Заполните `.env`:

- `DB_HOST` - хост базы данных (куда подключаться)
- `DB_PORT` - порт
- `DB_DATABASE` - название базы данных
- `DB_USERNAME` - пользователь
- `DB_PASSWORD` - пароль

Введите в терминал (в корне проекта):

- команду для установки пакетов: `composer require`
- команду для генерации спец. ключа приложения: `php artisan key:generate`
- команду для выполнения миграция (заполнения базы данных): `php artisan migrate`
